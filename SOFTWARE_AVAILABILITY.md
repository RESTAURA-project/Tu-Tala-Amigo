# Software availability

**Name:** RESTAURA  
**Description:** Open web platform for participatory phenological monitoring of native trees, designed to support citizen science initiatives and ecological restoration projects.  

**License:** GNU General Public License v3.0 or later (GPL-3.0-or-later)  

**Programming languages:**  
- PHP  
- JavaScript  
- HTML / CSS  

**Frameworks and libraries:**  
- Bootstrap  
- jQuery  

**Platform:** Web application (LAMP stack: Linux, Apache, MySQL, PHP)  

**Operating system:** Platform independent (web-based)  

**Repository:**  
https://github.com/RESTAURA-project/restaura  

**Persistent identifier (DOI):**  
https://doi.org/10.5281/zenodo.18200027  

**Documentation:**  
- Installation guide: `INSTALL.md`  
- Usage guide: `USAGE.md`  
- Data model description: `DATA_MODEL.md`  

**Geographical scope:**  
The software was initially developed for projects in Argentina and includes predefined geographic tables for Argentine provinces and localities. The database structure can be adapted to other countries by modifying or extending these tables.

**Availability:**  
The source code is publicly available and archived in Zenodo to ensure long-term preservation and reproducibility.
