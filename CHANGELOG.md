# Changelog

## v1.0.3 — 2026-01-09

### Added
- First public release of the RESTAURA web platform.
- User management system with role-based access (administrator and phenology roles).
- Registration of georeferenced tree specimens.
- Recording of standardized phenological events (budburst, flowering, fruiting, senescence).
- Optional upload of photographic evidence associated with observations.
- Interactive visualization of data through dashboards.
- Export of collected data in open formats (CSV and Excel).
- Responsive graphical user interface for use on mobile and desktop devices.

### Notes
- This version corresponds to the archived release associated with the Zenodo DOI.
