# Lista de verificación para una implementación de RESTAURA

Antes de habilitar el registro de participantes:

## Identidad del proyecto

- [ ] Definir el nombre público de la implementación.
- [ ] Identificar la institución responsable.
- [ ] Designar un correo electrónico de contacto.
- [ ] Definir la URL pública del proyecto.

## Datos y privacidad

- [ ] Enumerar los datos personales realmente recopilados.
- [ ] Identificar qué datos aparecen en las exportaciones científicas.
- [ ] Definir quién puede acceder a los datos personales.
- [ ] Definir dónde se almacenan y durante cuánto tiempo.
- [ ] Establecer el procedimiento para solicitar acceso, corrección o baja.
- [ ] Evaluar si las coordenadas requieren reducción de precisión o acceso restringido.
- [ ] Adaptar la Política de Privacidad a la legislación local.

## Fotografías y contenidos

- [ ] Elegir la licencia aplicable a las fotografías.
- [ ] Verificar que la licencia utilizada coincida con los usos previstos.
- [ ] Informar claramente la licencia antes del envío de imágenes.
- [ ] Registrar la aceptación de la licencia.

## Registro y consentimiento

- [ ] Incluir enlaces visibles a la Política de Privacidad y a los Términos de Uso.
- [ ] Incorporar casillas obligatorias de aceptación.
- [ ] Registrar la fecha y la versión de los documentos aceptados.
- [ ] Definir cómo se informarán cambios sustanciales.

## Revisión institucional

- [ ] Solicitar revisión del área legal, de protección de datos o del comité de ética, cuando corresponda.
- [ ] Confirmar que el texto describe el funcionamiento real de la implementación.
